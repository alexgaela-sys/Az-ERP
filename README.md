# AZ ERP

نقطة بداية منفصلة تماماً عن ريبو تشغيل سناك دب (`alexgaela-sys/abdalah-fathelbab`)، مأخوذة منه بتاريخ 2026-11-17 كأساس لمنتج ERP عام يُباع لأي نشاط.

## الفرق عن ريبو سناك دب

- **اتشال:** سكريبتات استيراد بيانات سناك دب (`scripts/`)، بيانات التشغيل الفعلية (`data/`, `snakdip_system_*.json`)، واختبارات UAT القديمة (`uat/`).
- **اتسيب:** محرك المحاسبة والمخازن والإنتاج (`src/services`)، شاشات الواجهة (`src/components`)، مخطط قاعدة البيانات ودوال Supabase (`supabase/`).

## قبل الاستخدام كمنتج قابل للبيع

هنا الحاجات اللي لسه محتاجة تتعمم (راجع المحادثة للتفاصيل):

1. **تعميم بيانات البداية**: `src/services/db.ts` فيه أصناف وحسابات مكتوبة بأسماء سناك دب. لازم تتحول لشاشة إعداد بدل بيانات ثابتة.
2. **فصل بيانات العملاء (Multi-tenancy)**: قاعدة البيانات حالياً بدون عزل بين عملاء مختلفين.
3. **مشروع Supabase منفصل**: لسه بيستخدم نفس إعدادات الاتصال — لازم مشروع جديد تماماً قبل أي بيانات حقيقية.
4. **معالج إعداد عام** بدل شاشة "الإعداد لأول مرة" المبنية لمصنع تصنيع بالتحديد.

## التشغيل محلياً

```bash
bun install
bun run dev
```

محتاج ملف `.env` (راجع `.env.example` لو موجود) بمفاتيح Supabase الخاصة بالمشروع الجديد — **مش مشروع سناك دب**.
